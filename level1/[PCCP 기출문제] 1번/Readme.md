# 동영상 재생기

## 문제
[프로그래머스 - 동영상 재생기] https://school.programmers.co.kr/learn/courses/30/lessons/340213

## 주요 제한사항
- 시간은 `"mm:ss"` 형식
- `commands`의 길이: 최대 100
- 명령은 `"prev"` 또는 `"next"`

## 풀이 과정
시간 계산과 비교를 쉽게 하기 위해 모든 시간을 초 단위로 변환했다.

시작 위치와 각 명령 실행 후의 위치가 오프닝 구간이면 오프닝 끝으로 이동시켰다.

`"prev"`는 현재 위치에서 10초를 빼되 0초 미만으로 내려가지 않게 하고, `"next"`는 10초를 더하되 동영상 길이를 넘지 않게 처리했다.

모든 명령을 실행한 후 최종 위치를 다시 `"mm:ss"` 형식으로 변환하여 반환했다.
