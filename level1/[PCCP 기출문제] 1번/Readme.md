# 동영상 재생기

## 문제
[프로그래머스 - 동영상 재생기] https://school.programmers.co.kr/learn/courses/30/lessons/340213

## 주요 제한사항
- 시간은 `"mm:ss"` 형식으로 주어진다.
- `commands`의 길이: 최대 100
- 명령은 `"prev"` 또는 `"next"`만 주어진다.
- 현재 위치가 오프닝 구간에 포함되면 오프닝이 끝나는 위치로 이동해야 한다.

## 풀이 과정
처음에는 `"mm:ss"` 형식의 문자열을 그대로 이용해 시간을 계산하는 방법을 생각했다.

하지만 문자열 상태에서는 10초 전이나 10초 후의 위치를 계산하고, 두 시간을 비교하기가 불편하다.

따라서 모든 시간을 초 단위의 정수로 변환했다.

먼저 시작 위치가 오프닝 구간에 포함되는지 확인하고, 포함된다면 오프닝이 끝나는 위치로 이동했다.

그다음 `commands`를 순서대로 확인하면서 `"prev"`이면 현재 위치에서 10초를 빼고, `"next"`이면 10초를 더했다.

이때 `"prev"`를 실행한 결과가 0초보다 작아지면 0초로 이동하고, `"next"`를 실행한 결과가 동영상 길이를 초과하면 동영상의 마지막 위치로 이동하도록 했다.

각 명령을 실행한 후 현재 위치가 오프닝 구간에 포함되는지도 다시 확인했다. 오프닝 구간에 포함된다면 현재 위치를 오프닝이 끝나는 위치로 변경했다.

모든 명령을 처리한 후 최종 위치를 다시 `"mm:ss"` 형식의 문자열로 변환하여 반환했다.
