# [PCCP 기출문제] 1번 _ 동영상 재생기

## 문제
[프로그래머스 - 동영상 재생기](https://school.programmers.co.kr/learn/courses/30/lessons/340213)

## 주요 제한사항
- 시간은 `"mm:ss"` 형식
- `commands`의 길이: 최대 100
- 명령은 `"prev"` 또는 `"next"`

## 풀이 과정
시간 계산과 비교를 쉽게 하기 위해 `split(":")`과 `map(int, ...)`으로 모든 시간을 초 단위로 변환했다.

시작 위치가 오프닝 구간이면 먼저 오프닝 끝으로 이동시켰다. 이후 각 명령을 실행한 뒤에도 오프닝 구간인지 확인했다.

`"prev"`는 10초를 빼되 `max()`로 0초 미만이 되지 않게 했고, `"next"`는 10초를 더하되 `min()`으로 동영상 길이를 넘지 않게 했다.

모든 명령을 실행한 후 `//`와 `%`로 분과 초를 구하고, `:02d`를 사용해 `"mm:ss"` 형식으로 반환했다.
