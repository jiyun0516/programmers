# 유연근무제

## 문제
[프로그래머스 - 유연근무제] (https://school.programmers.co.kr/learn/courses/30/lessons/388351?language=python3)

## 주요 제한사항
- 직원 수는 최대 1,000명이다.
- 직원마다 7일간의 출근 기록이 주어진다.
- 시각은 `시 × 100 + 분` 형태의 정수로 표현된다.
- `startday`는 이벤트 첫날의 요일이며, 월요일은 1, 일요일은 7이다.

## 풀이 과정
1. 출근 희망 시각을 분 단위로 바꾸고 10분을 더해 출근 인정 시각을 구한다.
2. 시작 요일과 날짜 인덱스를 이용해 각 기록의 요일을 계산한다.
3. 토요일과 일요일은 `continue`로 건너뛴다.
4. 평일에 인정 시각보다 늦게 출근했다면 `break`로 해당 직원의 검사를 끝낸다.
5. `for ... else`를 이용해 `break` 없이 검사를 마친 직원만 센다.

`8:55 + 10분 = 9:05`처럼 시가 바뀔 수 있으므로 시각을 분 단위로 변환해 비교한다.
