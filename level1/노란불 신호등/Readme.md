# 노란불 신호등

## 문제
[프로그래머스 - 노란불 신호등] (https://school.programmers.co.kr/learn/courses/30/lessons/468371)

## 주요 제한사항
- signals의 길이: 최대 5
- 각 신호등의 전체 주기: 최대 20초
- 전체 주기의 곱: 최대 20⁵ = 3,200,000

## 풀이 과정

각 신호등은 초록불, 노란불, 빨간불 순서로 같은 상태를 반복하며, 현재 주기에서의 위치는 나머지 연산으로 구할 수 있다.

각 신호등 주기의 곱은 모든 주기의 공배수이므로, 1초부터 주기의 곱까지 모든 신호등이 노란불인지 확인한다.

공배수 이후에는 이전 상태가 반복되므로, 그 안에서 찾지 못하면 `-1`을 반환한다.
