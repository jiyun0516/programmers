# 노란불 신호등

## 문제
[프로그래머스 - 노란불 신호등](https://school.programmers.co.kr/learn/courses/30/lessons/468371)

## 주요 제한사항
- `signals`의 길이: 최대 5
- 각 신호등의 전체 주기: 최대 20초
- 모든 신호등의 상태가 반복되는 주기: 각 주기의 최소공배수

## 풀이 과정
각 신호등은 초록불 → 노란불 → 빨간불 순서로 상태를 반복한다. 시간이 1초부터 시작하므로 `(time - 1) % (G + Y + R)`로 현재 주기에서의 위치를 구한다.

이 값이 `G` 이상 `G + Y` 미만이면 해당 신호등은 노란불이다. 1초부터 확인하면서 모든 신호등이 노란불인 첫 시각을 반환한다.

모든 신호등의 상태는 각 주기의 최소공배수만큼 시간이 지나면 똑같이 반복된다. 따라서 그때까지 찾지 못하면 `-1`을 반환한다.
